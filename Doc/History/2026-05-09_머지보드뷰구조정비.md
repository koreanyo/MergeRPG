## 작업 요약
UnitPieceView_1 프리팹 구조 정의 및 머지 루프 동작을 위한 코드 정비.

## 주요 작업 내용

### 1. MergeBoard 씬 설정 정비
- MergeBoard 오브젝트가 RectTransform 없이 일반 GO로 배치되어 있던 문제 수정
- Canvas 하위에 UI Empty로 재생성 → Panel_Bottom으로 통합
- 씬에 MergeBoard 인스턴스가 2개 존재해 싱글턴 충돌로 Panel_Bottom이 Destroy되는 문제 → 중복 제거

### 2. UnitPieceView_1 프리팹 구조 정의
각 자식 오브젝트의 역할 확정:
- **Bg**: 피스 카테고리(Unit/Item/Skill/Gimick) 색상. 현재 미정, 열어둠
- **Image**: 피스 구체적 종류 아이콘. 추후 테이블 연동
- **Border**: Bg 색상 종속 (동기화)
- **Piece_Tier_Txt/Lv**: "Lv." 고정 텍스트
- **Piece_Tier_Txt/Count**: 티어 숫자 표시

### 3. UnitPieceView.cs 개선
- `[RequireComponent(typeof(Image))]` 제거 (Bg가 레이캐스트 커버)
- SerializeField 추가: `_bgImage`, `_borderImage`, `_pieceImage`, `_countText`
- `RefreshVisual()` 변경: tier 색상 → 카테고리 색상(Bg/Border), Count 텍스트 갱신
- `GetCategoryColor()` 스텁 추가 (추후 테이블 정의 예정)
- `IDropHandler` 추가: 피스 위에 드롭 시 자신의 셀로 포워딩 → 머지 가능

### 4. MergeBoard.cs PlacePiece() 앵커 수정
피스 생성 시 anchorMin/Max를 (0,1)로 강제 설정. CellView와 기준 통일.
```csharp
rect.anchorMin        = new Vector2(0f, 1f);
rect.anchorMax        = new Vector2(0f, 1f);
rect.pivot            = new Vector2(0.5f, 0.5f);
rect.anchoredPosition = CellPosition(targetCell.col, targetCell.row);
```
