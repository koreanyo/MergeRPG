## 작업 목표
NullReferenceException 원인 파악, 명세 vs 현재 구현 비교, 이슈 정리

## 작업 내용

### 1. NullReferenceException 원인 파악 및 수정
- **증상**: CharacterView.cs:58 `BattleManager.Instance.QueueGaugeFull(this)` NullRef
- **원인**: Unity Enter Play Mode (Domain Reload 비활성화) → 이전 플레이 세션의 static Instance가 파괴된 오브젝트를 가리킨 채 유지됨
- **수정**: 7개 싱글턴에 `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` ResetStatic() 추가
  - BattleManager, DataManager, FloatingTextManager, GeneratorEnergy, Generator, MergeBoard, PopupManager
  - DataManager는 캐시 딕셔너리도 함께 Clear()
- **추가 수정**: CharacterView.Update()에 null 가드 추가

### 3. Generator Cell 설계 재확인
- 명세: grid[2,6], isGeneratorCell=true (6×7 = 42칸, 생성기 칸 제외 41칸 사용 가능)
- 사용자 의도: Generator는 셀과 별도의 버튼 UI → 보드는 6×7=42칸 전부 사용 가능
- 결론: 명세가 의도를 잘못 표현. 별도 UI 버튼으로 변경 시 isGeneratorCell 제거, IsEmpty 단순화
