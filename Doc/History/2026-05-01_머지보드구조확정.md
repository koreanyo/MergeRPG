## 작업 내용

### 1. 구조 파악
- CellView / MergeCell / UnitPieceView 프리팹 및 스크립트 분석
- CellView와 UnitPieceView는 부모-자식 관계가 아닌 동일 boardParent 아래 좌표 기반으로 공존
- CellView = 드롭 착지점 (IDropHandler), UnitPieceView = 드래그 실체 (IDragHandler)

### 2. MergeBoard 그리드 확정
- **7열 × 4행 = 28칸** (기존 6×7=42칸에서 변경)
- CellView 1 프리팹으로 교체 (기존 CellView.prefab → CellView 1.prefab)

### 3. GLG vs 수동 좌표 논의 결과
- GLG 사용 시 피스 레이어 위치 동기화 문제 발생 가능 → **수동 좌표 방식 확정**
- GLG 배치 방식(Upper Left 기준, padding 적용)을 수동 공식으로 동일하게 구현

### 4. MergeBoard.cs 수정 사항
| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| COLS | 6 | 7 |
| ROWS | 7 | 4 |
| cellSize | 90f | 120f (CellView sizeDelta와 동일) |
| cellSpacing | (없음) | 10f |
| paddingLeft/Top | (없음) | 40f |
| boardParent 필드 | SerializeField | 제거 → `GetComponent<RectTransform>()` |
| isGeneratorCell | col==2, row==6 | 제거 |
| CellPosition 기준 | 중앙 (0,0) | Upper Left (0,1) anchor 기준 |
| 생성 시 sizeDelta 설정 | (없음) | (120, 120) 명시 |
| anchor 설정 | (없음) | anchorMin/Max = (0,1), pivot = (0.5,0.5) |

### 5. MergeCell.cs 수정
- `isGeneratorCell` 필드 및 `IsEmpty` 조건에서 제거
