## 게임 방향 확정
- **장르**: 머지 + RPG + 로그라이트, 모바일

- **목표**: 상업화 예정

## 테이블 시스템 정비

### 문제 발견: EPPlus 라이선스
- 기존 `ExcelConverter.cs`가 EPPlus 라이브러리 사용 중
- EPPlus v5부터 상업용은 유료 라이선스 필요
- `LicenseContext.NonCommercial` 설정 상태 → 상업 배포 시 위반

### 해결: ExcelDataReader로 교체
- `ExcelDataReader.dll` (MIT 라이선스)이 이미 프로젝트에 포함되어 있었음
- `ExcelConverter.cs` 전면 재작성
- `EPPlus.dll`, `ICSharpCode.SharpZipLib.dll` 삭제

### 누락 파일 복구
- `TableSetting.cs` 미존재 → 신규 생성 (ScriptableObject)
- `TableSetting.asset`의 Script GUID 불일치 수정

### 잔재 코드 정리
- `ExcelTableEditor.cs` 삭제 (이전 게임 "Fishing2" 잔재, 중복 코드)

### 엑셀 테이블 구조 (확정)
| Row | 내용 |
|-----|------|
| Row 1 | 컬럼 타입 (`int`, `float`, `string`, `bool`, `notused`) |
| Row 2 | 컬럼 이름 |
| Row 3~ | 실제 데이터 |

- JSON 출력 경로: `Assets/Resources/Table/시트이름.txt`
- 임포트: Unity에서 `TableSetting` 에셋 선택 → Inspector의 "Import Table" 버튼
